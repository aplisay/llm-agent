# Release 0.9.36 — Hotfix: extra info logging

Single-commit hotfix on top of 0.9.35.

## Changes
- LiveKit worker now emits `info`-level log lines around session start, session started, and connect, making it easier to localise startup hangs in production.
- Stack-trace limit raised to 40 frames so deep async errors aren't truncated below the useful frame.
- Trimmed a couple of overly chatty Ultravox debug logs on call create.

Files: [agents/livekit/lib/worker.ts](../../agents/livekit/lib/worker.ts), [agents/livekit/plugins/ultravox/src/realtime/realtime_model.ts](../../agents/livekit/plugins/ultravox/src/realtime/realtime_model.ts).
