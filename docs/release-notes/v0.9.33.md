# Release 0.9.33 — callHooks and transfer feedback

Adds lifecycle webhooks for calls, richer feedback to the parent agent on warm-transfer outcomes, and two new transfer modes.

## Highlights

### Call lifecycle hooks (`callHook`)
Agents can now register a `callHook` URL that is fired on call **start** and **end**, giving operators a clean integration point for CRM updates, analytics, and downstream workflows. See [call-hooks.md](../../docs/call-hooks.md) for the payload spec.

### Warm-transfer feedback to the parent agent
When a warm transfer is rejected (busy, no answer, declined by the consult), the parent agent now receives a structured summary of *why* the transfer failed instead of an opaque error, so the agent can make a sensible spoken recovery. The transfer transcript handed back to the agent is also Markdown-quoted for readability ([transfer-handler.ts](../../agents/livekit/lib/transfer-handler.ts)).

### New transfer modes
- **`confidentialConsult`** — consult leg is invisible to the caller until completion.
- **`forceBridged`** — forces a bridged transfer even where a REFER would otherwise be attempted.
- The default for `consultFeedback` was swapped to match the more useful behaviour for most operators.

See [call-transfers.md](../../docs/call-transfers.md) for full semantics.

### Reliability fixes
- Resolved a race condition where the LiveKit agent could fail to leave the room cleanly after a transfer ([transfer-handler.ts](../../agents/livekit/lib/transfer-handler.ts), [worker.ts](../../agents/livekit/lib/worker.ts)).
- `GET /voices` is now resilient to upstream voice-provider hiccups ([lib/voices/index.js](../../lib/voices/index.js)).
- Outbound call failure reasons are now logged so operators can diagnose origination problems.
- Fix for [#96](https://github.com/aplisay/llm-agent/issues/96) in the function handler.

### Agent behaviour
- The agent is now guaranteed to speak first on a freshly answered call.
- Tightened validity checks on transfer destination numbers.

### Tests / CI
- The `/calls` endpoint test suite was made less brittle by reducing dependency on rate-limited external services.
