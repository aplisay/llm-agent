# Release 0.9.35 — Logging and Ultravox WebRTC model names

Merged via [PR #102](https://github.com/aplisay/llm-agent/pull/102). Small follow-up release tightening logging and Ultravox model-name handling.

## Highlights

### Ultravox WebRTC model name handling
Newer Ultravox models are now permitted on the WebRTC handler, with older model strings explicitly mapped to `v0.6` for backward compatibility ([lib/models/ultravox.js](../../lib/models/ultravox.js), [lib/handlers/handler.js](../../lib/handlers/handler.js)).

### Better function-invocation error logging
Function-call errors from the LiveKit agent now carry enough context to diagnose what was actually invoked and why it failed ([worker.ts](../../agents/livekit/lib/worker.ts), [lib/function-handler.js](../../lib/function-handler.js)).

### CI
- The OpenAI text-mode test was disabled pending a fix; it had become flaky.
