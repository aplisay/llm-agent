# Release 0.9.54 - Transfer status polling fix, organisation name on /api/me

Each item is tagged by subsystem: **core** (API server, REST API, database,
billing, auth, model drivers) and **livekit** (LiveKit voice worker and Ultravox
plugin).

## Fixes - core + livekit

- **[livekit] `transfer_status` polling** is exempt from the tool-loop breaker,
  which refuses and then hangs up on a model that calls one tool many times in a
  short window. A model polling a slow transfer could trip it and end a live
  call during the transfer.
- **[livekit] Exempt tool logging**: a poll that crosses the breaker's refuse
  limit still runs, and logs one `tool_loop` warning with `action: "exempt"`.
- **[core] `GET /api/me`** reports organisation name again.

## Upgrade notes

- **[core] Database schema** stays at v57. There is no new environment.
